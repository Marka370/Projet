## 🚦 Légende des licences

Chaque ressource porte une pastille. **Regarde-la avant d'utiliser quoi que ce soit.**

| Pastille | Signification | Ce qu'on peut faire |
|---|---|---|
| 🟢 | **Libre** (CC0, domaine public, MIT…) | Utiliser, modifier, et même mettre les fichiers dans ce dépôt |
| 🟡 | **Libre avec conditions** (CC BY = créditer l'auteur, pas de revente seule, etc.) | Utiliser en respectant les conditions (voir [LICENCES.md](LICENCES.md)) |
| 🔵 | **Outil / tutoriel / documentation** | S'en servir, pas de fichiers à récupérer |
| 🔴 | **Référence seulement** (contenu protégé, ré-upload interdit) | S'abonner / consulter, **ne jamais recopier ici** |

## ⚠️ Règle d'or

Ce dépôt contient **des liens et notre propre travail**, jamais de fichiers extraits de jeux (Naruto, etc.) ni d'addons Workshop recopiés. Voir [CONTRIBUER.md](CONTRIBUER.md).
